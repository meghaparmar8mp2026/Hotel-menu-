# Restaurant Ordering System

## Description
This is a simple Python-based Restaurant Ordering System. The program displays a menu with different food items and their prices. It allows the user to enter the name of an item they want to order, checks whether the item is available, and calculates the total price of the order.

The program also gives the user an option to add another item to the order.

## Menu
- Vegetable Fried Rice - Rs. 100
- Crispy Tacos - Rs. 50
- Biryani - Rs. 35
- Pav Bhaji - Rs. 80
- Aloo Paratha - Rs. 65

## Features
- Displays the restaurant menu
- Takes food orders from the user
- Checks item availability
- Calculates the total price
- Allows multiple items to be ordered
- Displays the final order amount

## Technologies Used
- Python
- Python Dictionary
- Conditional Statements
- While Loop
- User Input
- Variables

## How to Run
1. Make sure Python is installed on your computer.
2. Open the Python file `vityarthi1_project.py`.
3. Run the program.
4. Enter the name of the food item you want to order.
5. Choose whether you want to add another item.
6. The program will display the total price.

## Purpose
This project is created to practice basic Python programming concepts such as dictionaries, loops, conditional statements, input handling, and arithmetic operations.
