# Project Statement

## Restaurant Ordering System

The objective of this project is to create a simple restaurant ordering system using Python. The program displays a menu containing different food items and their prices. The user can enter the name of the item they want to order, and the program checks whether the item is available in the menu.

If the item is available, its price is added to the total order amount. The user can also choose to add more items to the order. Finally, the program displays the total price of all the items ordered.

## Problem Statement

Restaurants need a simple way to manage customer orders and calculate the total bill. This project provides a basic console-based solution where customers can select food items from a menu and get the total price automatically.

## Objectives

- To create a simple restaurant ordering system.
- To display food items and their prices.
- To accept food orders from the user.
- To check the availability of ordered items.
- To calculate the total price of the order.
- To allow the user to add multiple items.

## Expected Outcome

The program successfully takes food orders, checks the selected items against the menu, calculates their total price, and displays the final amount to the user.

## Conclusion

This project helps in understanding basic Python programming concepts such as dictionaries, variables, user input, conditional statements, loops, and arithmetic operations.
